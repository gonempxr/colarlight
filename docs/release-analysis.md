Игра уже полноценная: цикл добычи, 21 глубина (будет 30), менеджеры, «Нырнуть глубже», пазл, музей, рыбалка, задания, гардероб, 4 языка, версии для ПК и телефона, офлайн-доход, автотесты.

**Совет:** после этого обновления заморозить новые функции. Затем 1–2 недели провести закрытую бету с друзьями, после неё релиз.

## Что желательно

- **Yandex Игры.** Это самый крупный русскоязычный портал для веб-игр. По моему исследованию 29.09 там есть облачные сохранения и вход, а реклама не обязательна. Нужна интеграция их SDK и модерация (пауза при потере фокуса, без внешних ссылок). Это решает пункт 3 и даёт аудиторию.
- **Баланс по данным беты.** Сейчас симулятор даёт 2-ю глубину через ~4 минуты, первое «Нырнуть глубже» через ~2 часа, последнюю глубину через ~30 часов. Проверить это на живых людях.
- **Цели для конца игры.** Что делать после последней глубины: рекорды, награды за стадии 20/20, коллекция рыб.

## Риски

- **Новое расширение** (вторая лодка и завод, 30 глубин, 20 стадий) добавляет риск багов прямо перед релизом. Поэтому после него заморозка и бета.
- **Скорость на слабых телефонах.** Каждое обновление графики добавляет нагрузку, последнее прибавило 6–12% в моём тесте. Нужна проверка на реальном устройстве.
- **Детская аудитория.** Если позиционировать игру для детей, никаких платных случайностей и никакого сбора данных. Сейчас так и есть.
